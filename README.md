# Xephira Lab (`packages/apps/XephiraLab`)

Flagship OxygenOS 17 Aquamorphic & Apple iOS 18 Spatial Liquid Glass customization suite for **XephiraOS** (Android 16 / LineageOS 23.2).

---

## 💎 Features

### 1. Liquid Glass Optics
- **Gaussian Blur Intensity**: Real-time SurfaceFlinger blur slider (0 - 48 dp).
- **Specular Edge Reflection**: Dynamic light refraction angle on continuous squircle card borders.
- **Chromatic Aberration**: Subtle prism refraction along high-contrast boundaries.

### 2. Spatial Kinetic Physics
- **120Hz ProMotion Spring Physics**: Apple iOS 18 fluid gesture response with natural bouncy deceleration.
- **Predictive Back Transformation**: Fluid scaling and corner radius warping during back swipe navigation.

### 3. Continuous Curvature Studio
- **Superellipse Exponent ($n=4$)**: Continuous squircle curvature standard eliminating corner pinch.
- **G2 Tangency Continuity**: Native alignment with OnePlus OxygenOS 17 Aquamorphic design language.

### 4. Flux Silicon & Memory Telemetry
- **Liquid RAM Boost**: Dynamic allocation of zRAM swap space (+4 GB, +8 GB, +12 GB).
- **Hyper-Rendering Governor**: Frame pacing and frame-drop suppression for locked 120 FPS UI.
